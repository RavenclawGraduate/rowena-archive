# Code Converter 编程语言转换器
一款完全运行在浏览器本地的编程语言互转工具，支持明暗双主题，内置源码查看功能。

## ✨ 功能特性
- 🔒 **本地运算**：所有代码转换逻辑在浏览器内执行，不会上传任何用户代码至服务器
- 🎨 浅色/深色双主题一键切换
- 🔄 语言互换、一键清空编辑器、内置多组示例模板
- 📄 内置【查看源码】按钮，一键复制完整页面代码自由修改

## ⚠️ 重要提示
1. 自动代码转换结果仅作参考，请人工校验代码逻辑，工具不保证转换代码可直接运行。
2. 代码编辑器推荐本地安装 Cascadia Code / Fira Code / JetBrains Mono 等宽字体，获得最佳显示效果。

## 🚀 使用方式
方式1：直接本地打开 `code-converter.html`
方式2：访问在线部署地址
